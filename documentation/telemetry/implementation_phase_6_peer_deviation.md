## 🎯 Phase Overview

### Purpose

Implement **peer comparison** to identify units that are underperforming relative to their fleet:

- **Fleet Context**: Compare each unit against similar units (same model)
- **Relative Performance**: Detect degradation even when absolute values are "normal"
- **Statistical Rigor**: Use percentiles and z-scores for robust comparison
- **Explainable**: Show where unit ranks within fleet (e.g., "bottom 10%")

### Why This Phase Matters

**Absolute thresholds miss relative degradation**:
- Unit may have "normal" oil temperature (85°C)
- But if fleet average is 75°C, this unit is underperforming by 10°C
- Phase 2 techniques won't catch this (no absolute threshold violation)
- Peer deviation identifies: "This unit runs 10°C hotter than peers"

**Real-world example**:
- Unit A: `EngCoolTemp` = 88°C (within P1-P99 baseline)
- Fleet average: 80°C ± 5°C
- Unit A is at 97th percentile → abnormally hot relative to peers
- **Peer deviation detects this; threshold deviation does not**

### Why This Is Phase 6 (After Advanced Rules, Before Change-Point)

**Rationale**:
1. ✅ **Highly Explainable**: Percentile ranks are intuitive ("bottom 15% of fleet")
2. ✅ **Complements Phase 2**: Catches failures missed by absolute thresholds
3. ✅ **Moderate Complexity**: Requires fleet aggregation but no ML
4. ✅ **Fast Implementation**: 2-3 days
5. ✅ **Before ML Techniques**: Keep explainable techniques first

### Key Principle

**Context matters.** A signal value that's "normal" in isolation may be abnormal relative to peers. Peer comparison adds essential fleet context.

```python
class FleetBaselineGenerator:
    def generate_fleet_baseline(self, week, client, equipment_model):
        """Generate fleet statistics for one week."""
        # Load all units' weekly aggregates
        unit_aggregates = self.load_weekly_aggregates(week, client, equipment_model)
        
        # For each signal:
        for signal in self.signal_registry.get_all_signals():
            signal_values = unit_aggregates[signal].dropna()
            
            # Exclude outliers (top/bottom 5%)
            q5, q95 = signal_values.quantile([0.05, 0.95])
            filtered = signal_values[(signal_values >= q5) & (signal_values <= q95)]
            
            # Calculate fleet stats
            fleet_stats = {
                'P5': filtered.quantile(0.05),
                'P25': filtered.quantile(0.25),
                'P50': filtered.quantile(0.50),
                'P75': filtered.quantile(0.75),
                'P95': filtered.quantile(0.95),
                'mean': filtered.mean(),
                'std': filtered.std(),
                'N': len(filtered)
            }
            
            # Store
            self.save_fleet_baseline(week, client, equipment_model, signal, fleet_stats)
```

### Day 41: Peer Deviation Implementation

**Morning** (4 hours): **Peer Comparison Logic**

**Tasks**:
1. Implement `PeerDeviation` technique class
2. Load unit's weekly aggregate (from Phase 2)
3. Load fleet baseline for same week + client + model
4. Calculate peer deviation metrics:
   - **Percentile Rank**: Where does unit sit in fleet? (0-100)
   - **Z-Score**: How many standard deviations from fleet mean?
   - **Delta from P50**: Absolute difference from fleet median
5. Classify deviation severity:
   - **Normal**: Z-score ∈ [-1, +1] (within 1 std)
   - **Alerta**: Z-score ∈ [-2, -1) or (+1, +2] (1-2 std)
   - **Anormal**: Z-score < -2 or > +2 (>2 std from fleet)

**Deviation Calculation**:
```python
class PeerDeviation(BaseTechnique):
    def calculate_peer_deviation(self, unit_value, fleet_stats):
        """Calculate how unit compares to fleet."""
        # Z-score
        z_score = (unit_value - fleet_stats['mean']) / fleet_stats['std']
        
        # Percentile rank (approximate)
        # Use normal distribution assumption
        from scipy.stats import norm
        percentile_rank = norm.cdf(z_score) * 100
        
        # Delta from median
        delta_from_p50 = unit_value - fleet_stats['P50']
        
        # Severity classification
        if abs(z_score) <= 1:
            severity = 'Normal'
        elif abs(z_score) <= 2:
            severity = 'Alerta'
        else:
            severity = 'Anormal'
        
        return {
            'z_score': z_score,
            'percentile_rank': percentile_rank,
            'delta_from_p50': delta_from_p50,
            'severity': severity
        }
```

**Afternoon** (4 hours): **Risk Score Normalization**

**Tasks**:
1. Convert z-score to risk score (0-100 scale)
2. Apply signal criticality weights (from signal registry)
3. Calculate confidence score:
   - Penalty if fleet sample size <5 units
   - Penalty if unit data quality <80%
   - Penalty if unit is itself an outlier (excluded from fleet stats)
4. Build evidence dictionary:
   - Fleet percentiles (P25, P50, P75)
   - Unit value
   - Percentile rank
   - Z-score
   - "Unit ranks in bottom 12% of fleet"

**Risk Score Formula**:
```python
def calculate_risk_score(self, z_score, signal_criticality):
    """Convert z-score to 0-100 risk score."""
    # Base score from z-score magnitude
    # |z| = 0 → score = 0
    # |z| = 1 → score = 30
    # |z| = 2 → score = 70
    # |z| = 3+ → score = 100
    
    base_score = min(100, abs(z_score) * 35)
    
    # Apply signal criticality multiplier
    risk_score = base_score * signal_criticality
    
    return min(100, risk_score)
```

### Troubleshooting

**Issue**: Fleet size too small (<5 units)
- Check if equipment_model is too specific (e.g., "CAT 789D Rev3" vs. "CAT 789D")
- Consider aggregating across similar models
- Accept lower confidence for small fleets

**Issue**: Unit excluded from fleet (outlier)
- This is expected for top/bottom 5%
- Unit still gets peer deviation calculated (vs. remaining fleet)
- Confidence score will be lower

**Issue**: Results show all units as "Normal"
- Check if fleet variance is too high (std >> mean)
- Verify z-score thresholds (may need tightening)
- Check if signal data quality is poor
